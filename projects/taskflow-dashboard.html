View Live Demo View Source Code

Project Overview

TaskFlow is a React-based project management tool built to help teams organize and track their work visually. It mirrors the core experience of tools like Jira or Linear — a drag-and-drop board, detailed task views, and an overview dashboard — all built as a single-page React application.

Key Features

  • Drag-and-drop Kanban board for moving tasks between stages
  • List view toggle as an alternative to the board
  • Task detail panel with comments and subtasks
  • Dashboard overview with project stats
  • Team workload charts
  • State managed with React Context API for a smooth, app-like feel
