Lumora — E-Commerce Store

A multi-page fashion storefront with a working cart, wishlist, category filters, sorting, and a full checkout flow with order summary and payment method selection.

View Live Demo View Source Code

Project Overview

Lumora was built to simulate a real fashion e-commerce experience — from browsing products to completing checkout. The goal was to demonstrate a complete shopping flow that a real online store could use, with clean navigation and a polished, modern look.

Key Features

  • Shopping cart with quantity controls and live totals
  • Wishlist to save items for later
  • Category filters and product sorting
  • Multi-step checkout flow
  • Order summary with payment method selection
  • Fully responsive multi-page layout

My Role

Built the complete front-end architecture across multiple pages, including cart/wishlist logic in JavaScript and all page layouts.
