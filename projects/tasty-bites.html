Tasty Bites — Restaurant Website

A fully responsive restaurant landing page built to help a restaurant showcase its menu and attract online orders. It includes a filterable menu, an image gallery with lightbox, a testimonial slider, and a fully validated contact form.

View Live Demo View Source Code

Project Overview

This project was built for a restaurant that needed a fast, mobile-friendly website to showcase its menu and build trust with new customers. Every section — from the menu to the contact form — was designed to load quickly and work smoothly on any device, so visitors can browse and get in touch without friction.

Key Features

  • Filterable food menu, organized by category
  • Image gallery with a lightbox popup for food photos
  • Customer testimonial slider to build trust
  • Fully validated contact form with error messages
  • Mobile-first responsive layout for phones and tablets
  • Smooth scroll navigation between sections

Tech Stack

My Role

Designed and developed the full front-end from scratch, including layout, styling, and all interactive JavaScript functionality.
